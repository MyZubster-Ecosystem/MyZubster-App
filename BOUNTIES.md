# Bounties — MyZubster App

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Mobile/client bounties may cover UI/UX, accessibility, API integration, local-state safety, QR/camera flows, privacy/Tor verification, tests, documentation and error handling.

## Evidence

Use reproducible mobile tests, screenshots/video where helpful, API contract evidence and explicit device/build information.

## Reward truth

A UI that displays a wallet/payment state does not prove external settlement. MYZ in the core platform is currently an internal reward/accounting ledger. External XMR/token `PAID` requires independent evidence from the applicable rail.

## Privacy

Do not store or publish wallet seeds/private keys, auth tokens or unnecessary user data. Tor/Orbot work must verify actual routing rather than infer anonymity from app state.

## Issues

Use this repository's GitHub issues and link the implementation PR to the bounty issue.
